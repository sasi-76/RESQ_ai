## 🚨 **TROUBLESHOOTING**

### **Common Issues:**

#### **App Won't Start**
```bash
# Check: Node version
node --version  # Should be 16+

# Check: Dependencies installed
npm install

# Check: Port availability
# Port 3002 should be free

# Fix: Clear cache
rm -rf node_modules
rm package-lock.json
npm install
```

#### **Features Not Working**
```bash
# Check: Console for errors (F12)
# Check: AppContext is imported
# Check: Functions are in context value
# Fix: Hard refresh (Ctrl+Shift+R)
```

#### **Live Data Not Loading**
```bash
# Check: .env file exists
# Check: API keys are set
# Check: Network tab for failed requests
# Fix: Wait 1 minute (rate limit)
# Fix: Use mock data fallback
```

#### **Build Fails**
```bash
# Check: No TypeScript errors
# Check: All imports correct
# Check: No circular dependencies
# Fix: npm run build --verbose
```
